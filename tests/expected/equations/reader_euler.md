### euler

index: 0
flags: (none)

Dynare offsets apply only the predetermined-variable convention conversion.

- `y`: endogenous, written offset 0, Dynare offset 0, predetermined
- `rho`: parameter, written offset 0, Dynare offset 0
- `y`: endogenous, written offset -1, Dynare offset -1, predetermined
- `c`: endogenous, written offset 1, Dynare offset 1, forward-looking
- `e`: varexo, written offset 0, Dynare offset 0
