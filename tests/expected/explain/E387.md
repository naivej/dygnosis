### E387: Name is not exogenous

A name in a shock slot is declared, but is neither a ``varexo`` nor a ``varexo_det``: an endogenous variable or a parameter. Dynare refuses: `{name} is not exogenous.` The slots are the ``varexo`` row of ``matched_irfs`` and of ``matched_irfs_weights``.

For the ``irf_calibration`` shock, Dynare's own sentence names the row's endogenous instead: `Variable {endo} is not an exogenous.` That sentence is this code as well.

**Fix**

Name a ``varexo`` variable.
