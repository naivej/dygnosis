### E288: Undeclared name in the epilogue block

An expression in the ``epilogue`` block uses a variable or function name that is not declared before it. Dynare refuses: `Variable bar used in the epilogue block but was not declared.` Unknown calls do not implicitly declare functions in this block.

**Warrant**

For a call, the editor highlights the undeclared function name; Dynare's parse range can include its arguments.

**Fix**

Declare the symbol or function before the block, or correct the name.
