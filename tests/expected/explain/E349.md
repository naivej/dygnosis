### E349: markov_switching parameters names are not parameters

A name in the ``parameters=[…]`` option of ``markov_switching`` is not a declared parameter. Dynare refuses: `Variables passed to the parameters option of the markov_switching statement must be parameters. Caused by: Y`.

The name must have the required type when this row, head, or option is read. Earlier successful `change_type` statements count; later declarations or type changes do not. Repeated macro copies use their own parser context.

**Fix**

List only ``parameters`` names, or declare the name as a parameter.
