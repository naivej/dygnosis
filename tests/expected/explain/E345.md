### E345: markov_switching statement missing a required option

``markov_switching`` was written without one of ``chain``, ``number_of_regimes`` or ``duration``. Dynare refuses: `A 'chain' option must be passed to the 'markov_switching' statement.` with the missing option named.

**Fix**

Pass the named option.

**Range warrant**

A missing chain, regime count, or duration selects the `markov_switching` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
