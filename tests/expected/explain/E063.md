### E063: Undefined macro interpolation

An active line still contains an unresolved `@{NAME}` macro interpolation after the language server applied the simple `@#define` substitutions it can evaluate. Dynare's macro preprocessor cannot produce valid model code unless that macro name is defined in scope.

**Fix**

Define the macro with `@#define NAME = value` before the line that uses it, correct the macro name, or remove the interpolation.
