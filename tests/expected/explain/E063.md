### E063: Undefined macro name

An active macro expression or definition uses an undefined variable or function. Dynare refuses during macro processing: `Unknown variable NAME` or `Unknown function NAME`. The diagnostic points to the directive or interpolation that uses the name.

**Fix**

Define the variable or function with `@#define` before it is used, or correct its name. A valid expression that Dygnosis cannot evaluate instead leaves expansion incomplete; it is not this Error.
