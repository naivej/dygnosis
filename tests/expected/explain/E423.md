### E423: Learnt-in endval needs expectation-errors commands

A nondefault `endval(learnt_in=…)` block needs both expectation-errors setup and solver, without regular perfect-foresight setup or solver. Dynare refuses: `the 'endval(learnt_in=…)' block can only be used in conjunction with the 'perfect_foresight_with_expectation_errors_setup' and 'perfect_foresight_with_expectation_errors_solver' commands.`

**Fix**

Use the expectation-errors setup and solver, or use ordinary `endval`.
