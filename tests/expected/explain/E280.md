### E280: external_function name used as a variable inside model

A name declared with ``external_function(name=…)`` is used as a bare variable in a model expression. This includes model equations, external-function arguments, planner objectives, constraints, growth factors and deflators. The role is the one known when this use was parsed. Dynare refuses: `Symbol {name} is a function name external to Dynare. It cannot be used like a variable without input argument inside model.`

**Fix**

Call the function with arguments, or use a different name.
