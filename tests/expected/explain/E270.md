### E270: shocks skewness on a non-exogenous name

An ordinary ``shocks`` block holds skewness on a name that is not an aggregate exogenous variable. Dynare refuses: `shocks: setting skewness for '{a}', '{b}', '{c}' is not allowed; skewness can only be specified for exogenous variables`. In Dynare 7.2, an ordinary block, including ``shocks(learnt_in=1)``, also consumes skewness retained by preceding ``shocks(heterogeneity=…)`` blocks.

**Warrant**

Dynare prints this Check refusal without a source range. The diagnostic points to the written skewness row, including a row retained from a heterogeneous block.

**Fix**

Use ``skew`` only on aggregate ``varexo`` names when an ordinary shocks block consumes it.
