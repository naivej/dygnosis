### E130: Variable used before assignment in steady_state_model

The ``steady_state_model`` block evaluates assignments in order. An ordinary endogenous or temporary variable on a right-hand side must already have been assigned in an earlier row. Parameters and exogenous values do not require an earlier steady-state assignment. Dynare refuses: `variable 'n' is undefined in the declaration of variable 'log_n'`. For multiple outputs, the sentence names the first output of the row.

This check uses final symbol types after successful `change_type` statements. Written ``ramsey_model`` and ``ramsey_policy`` commands exempt this order check for conditional steady states.

**Warrant**

The diagnostic points at the right-hand-side name. The message keeps Dynare's sentence without its block and line prefix; the editor range and MCP location carry that information.

**Fix**

Assign the endogenous or temporary value in an earlier steady-state row before using it.
