### W022: Parameter declared but never referenced in model equations

A parameter is declared but has no surviving use in aggregate dynamic or static-only equations, live model-local definitions, heterogeneous equations, or `steady_state_model`. Parameters assigned as targets in `steady_state_model` count as used. A parameter named by the `discount` option of `pac_model` counts as used. Calibration, `initval`, and shock expressions do not count as uses. Dynare warns: `Parameter(s) unused_p not used in the model`. Dynare can still warn for a discount-only parameter at check, because it substitutes that discount while rewriting the model. Dygnosis reports one warning per written unused parameter and omits generated names such as `optimal_policy_discount_factor`. The check also applies to a complete file without a `model` block. An included declaration keeps the warning in that file, once for each requested root analysis.
