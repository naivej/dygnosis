### E026: varexo_det with a perfect-foresight solver

A ``varexo_det`` declaration cannot appear with ``simul``, ``perfect_foresight_solver``, or ``perfect_foresight_with_expectation_errors_solver``. Dynare refuses: `A .mod file cannot contain both one of {perfect_foresight_solver, simul, perfect_foresight_with_expectation_errors_solver} and varexo_det declaration (all exogenous variables are deterministic in this case)`.

**Fix**

Remove the ``varexo_det`` declaration (use ``varexo``), or drop the perfect-foresight solver.

**Range warrant**

The range selects the `varexo_det` keyword that owns the first affected declaration. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
