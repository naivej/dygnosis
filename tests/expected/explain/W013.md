### W013: Equation count does not match endogenous variable count

The number of equations inside the `model` block does not equal the number of endogenous variables declared in the `var` block.

When ramsey_model, ramsey_policy, or discretionary_policy is present and instruments= lists N unique names, the expected gap is −N, not equality; a square file still warns.

**Fix**

- Add a missing equation, or remove a duplicate one
- Declare the missing endogenous variable in `var`, or remove an   extra declaration
- Check whether a commented-out equation was intended to be   active
- For ramsey_model / ramsey_policy / discretionary_policy with N instruments, the intended gap is −N; do not add equations only to make the file square
