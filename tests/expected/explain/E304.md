### E304: @#includepath is not a directory

The ``@#includepath`` argument does not resolve to an existing directory (a relative path resolves against the root model's invocation directory, including directives in included files). Dynare refuses: `missing_dir does not evaluate to a valid directory`.

**Warrant**

Dynare prints that line inside a `Macro-processing error: backtrace…` block that also repeats the directive and its location; the editor reports the single line.

**Fix**

Point the directive at an existing directory, or create it.
