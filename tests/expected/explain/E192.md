### E192: Plain heterogeneous equation count mismatch

The number of written equations and endogenous variables in a heterogeneity dimension does not match. Dynare refuses: `There are 1 equations but 2 endogenous variables in the model for heterogeneity dimension 'h'!` Dynare may change these counts when it rewrites a model. W208 provides guidance for other written-count mismatches.

**Warrant**

The transport already labels Errors, so the diagnostic omits Dynare's severity prefix.

**Fix**

Match model equations to distinct endogenous variables in that dimension.

**Range warrant**

The range selects the first safely mapped `model` keyword for the affected heterogeneity dimension. The count still combines that dimension's blocks. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
