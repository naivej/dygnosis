### E300: Several ramsey_policy statements

The file has more than one ``ramsey_policy`` statement. Dynare refuses: `Several 'ramsey_policy' statements cannot appear in a given .mod file.`

**Fix**

Keep a single ``ramsey_policy`` statement.

**Range warrant**

The range selects the offending `ramsey_model` or `ramsey_policy` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
