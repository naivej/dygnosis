### E278: Division by a denominator that folds to zero

Dynare simplifies written expressions as it reads them, before MATLAB runs. A written `0` is treated differently from `0.0` or `0e0`. Simplification can make a denominator zero, for example `p^0-1`, `p/p-1`, or `p-p`. Dynare refuses: `Division by zero when forming ({num})/(0); denominator simplified to 0 (possibly after substituting a variable set to 0).` The message uses the simplified numerator: `(p/p)/(p^0-1)` reports `(1)/(0)`. Dynare checks an expression inside-out, so an error in a fraction is still reported even when a later multiplication by zero would remove it. Parameter assignments do not replace names with their values while the file is parsed. If parsing stops with an Error, later checks such as E021, W022, and W042 do not run.

**Fix**

Change the denominator so it is not zero.
