### E328: external_function second derivative from another function

The first derivative comes from the top-level function while ``second_deriv_provided`` names a different external function. Dynare refuses: `If the first derivative is provided by the top-level function, the second derivative cannot be provided by any other external function.`

**Fix**

Provide the second derivative in the same function (a bare ``second_deriv_provided``), or name a first-derivative function.
