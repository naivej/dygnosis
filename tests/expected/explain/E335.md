### E335: Equation-surgery tag matched no equation

A ``model_remove`` / ``model_replace`` tag set names no equation of the model. Dynare refuses: `model_remove/model_replace/exclude_eqs/include_eqs: The equations specified by <tag list> were not found.`

**Fix**

Check the tag value against the ``[name='...']`` tags of the model block, or drop the tag.
