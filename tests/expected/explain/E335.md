### E335: Equation tag selection matched no equation

A tag selection for `model_remove`, `model_replace`, `include_eqs` or `exclude_eqs` matched no equation.

**Fix**

Check both the tag key and value against the model equations, for example `name='policy'` or `group='policy'`. For an analysis configuration, change or clear the equation selection. See [Dynare's equation-selection rules](https://www.dynare.org/manual/running-dynare.html#exclude-eqs).
