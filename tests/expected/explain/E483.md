### E483: Equation selection leaves unmatched static and dynamic rows

The selected invocation removes different numbers of equations tagged `static` and `dynamic`. Dynare refuses: `exclude_eqs/include_eqs: You must remove the same number of equations marked `static` as equations marked `dynamic`.`

Select both sides of each static/dynamic pair. This check runs after the full source has passed Parse and Check. No selected model facts are returned when selection fails.
