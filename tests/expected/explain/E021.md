### E021: Exogenous variable never referenced in model

A shock declared in `varexo` has no surviving use in the model equations. Dynare refuses: `unused_exo not used in model block. To bypass this error, use the nostrict option. This may lead to crashes or unexpected behavior.` The check also applies to a complete file without a `model` block. Names removed by Parse simplification do not count as uses, and a name used only by an unused model-local definition does not count. Observed exogenous names and PAC growth or component-growth uses are exempt. An E021 Error stops the later unused-endogenous E186 check. A `varexo_det` declaration does not count — Dynare accepts one that is never used.
