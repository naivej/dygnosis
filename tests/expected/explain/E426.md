### E426: Removed variable used in a model expression

A model expression uses a variable after `model_remove` or `var_remove` changed its type to excluded. This includes planner objectives and Ramsey constraints. Dynare refuses: `Variable 'c' can no longer be used since it has been excluded by a previous 'model_remove' or 'var_remove' statement`. A use written before the removal is allowed.

**Fix**

Keep the variable in the model, or stop using it after its removal.
