### E426: Removed variable used in a model expression

A model expression uses a variable after `var_remove` changed its type to excluded. Dynare refuses: `Variable 'c' can no longer be used since it has been excluded by a previous 'model_remove' or 'var_remove' statement`. A use written before the removal is allowed.

**Fix**

Remove the `var_remove` statement or stop using that variable after it.
