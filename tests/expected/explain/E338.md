### E338: data statement without file or series

The ``data`` statement carries neither ``file`` nor ``series``. Dynare refuses: `The file or series option must be passed to the data statement.`

**Fix**

Pass exactly one of the two: ``data(file='x.csv');`` or ``data(series=y);``.

**Range warrant**

The missing-source branch selects the `data` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
