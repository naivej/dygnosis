### E474: Command not supported for heterogeneous models

A heterogeneity dimension is declared together with ``model(block)`` or a command Dynare 7.2 does not run on heterogeneous models. Dynare refuses, for example: `The 'check' command is not supported for heterogeneous models` or `the 'block' option of the 'model' block is not supported for heterogeneous models`.

**Fix**

Remove that command or option, or drop the heterogeneity dimension.
