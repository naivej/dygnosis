### E466: Heterogeneous shock standard error on the wrong type

A ``shocks(heterogeneity=…)`` block sets a standard error on a name that is not a heterogeneous exogenous variable. Dynare refuses: `shocks: setting a standard error on 'y' is not allowed, because it is not a heterogeneous exogenous variable`.

**Fix**

Set the standard error on a ``varexo(heterogeneity=…)`` name.
