### E103: osr is missing osr_params or optim_weights

Optimal simple rules (``osr``) need an ``osr_params`` statement (the parameters to optimise). They refuse when it is missing: `The osr statement requires the osr_params statement.` They also refuse when neither ``optim_weights`` nor ``planner_objective`` is present: `The osr statement requires either an optim_weights block or a planner_objective.` This check flags a missing ``osr_params`` statement and a missing ``optim_weights`` block.

**Fix**

Add the missing ``osr_params`` statement and/or ``optim_weights`` block.
