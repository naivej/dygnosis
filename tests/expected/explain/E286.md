### E286: with_epilogue without an epilogue block

A ``shock_decomposition``, ``realtime_shock_decomposition``, or ``initial_condition_decomposition`` statement has the ``with_epilogue`` option, but the file has no ``epilogue`` block. Dynare refuses: `the 'with_epilogue' option cannot be specified when there is no 'epilogue' block`.

**Fix**

Add an ``epilogue;`` … ``end;`` block, or drop the ``with_epilogue`` option.
