### E023: Predetermined variable not declared endogenous

A name listed in `predetermined_variables` must be an aggregate endogenous variable when the command is read. A heterogeneous variable declared with `var(heterogeneity=...)` is not eligible. Dynare refuses an unknown name with `Unknown symbol: NAME` and a declared name of the wrong type with `NAME is not endogenous.`

An earlier successful `change_type(var)` makes a name eligible. A later declaration or type change cannot validate an earlier command.

**Warrant**

The editor points at the name and uses a command-specific sentence for both official refusals.

**Fix**

- Declare an intended aggregate endogenous variable with `var` before the command.
- Remove a heterogeneous variable from the command and write its leads and lags directly in its equations.
- Remove any other ineligible name from the command.
