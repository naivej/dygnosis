### E023: Predetermined variable not declared endogenous

A name listed in `predetermined_variables` must also be declared as an endogenous variable in the `var` block. Dynare refuses: `Unknown symbol: e`.

**Warrant**

The editor names the `predetermined_variables` role; Dynare's parse string is the generic `Unknown symbol`.

**Fix**

- Add the variable to the `var` declaration, or
- Remove it from `predetermined_variables` if it is not actually   endogenous
