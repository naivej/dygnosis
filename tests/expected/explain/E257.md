### E257: Default equation tag collides with existing name

An equation has no explicit ``name`` key. Dynare cannot use an available variable name from its left-hand side, and the equation's one-based number is already used as a name. An explicit ``name`` key, even with an empty value, prevents Dynare from assigning either default. Dynare refuses: `Error creating default equation tag: cannot assign default tag to equation number {n} because it is already in use`.

**Fix**

Give the equation an explicit ``[name=…]`` that does not collide.
