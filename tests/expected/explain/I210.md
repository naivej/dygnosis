### I210: Number written in an equation

A written model equation contains a numeric literal other than 0 or 1. This is a writing preference, not a Dynare refusal. The note does not evaluate parameter values or rewrite calibration.

`[static]` equations are included. `#` definitions are not. Timing offsets, tags, options, comments, and strings are not counted. A unary minus uses the literal's magnitude, so `-1` is quiet.
