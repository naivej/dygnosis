### E062: Macro syntax error

A Dynare macro `@#if` block has no matching `@#endif`, a `@#for` block has no matching `@#endfor`, or a function definition ends while its expression still needs an operand. Dynare refuses during macro parsing; a trailing operator in `@#define f(x) = x+` prints `syntax error, unexpected EOL`.

**Warrant**

For unmatched blocks, the editor names the opener or stray closer and points at that directive; Dynare's bison location does not.

**Fix**

Close the macro block with the matching directive, or complete the function expression before the end of the definition.
