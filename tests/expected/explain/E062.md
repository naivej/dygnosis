### E062: Macro syntax error

A macro directive or expression does not match Dynare syntax. Each file is parsed before its macros run, including inactive branches, empty iterations, and function bodies. An included file is parsed separately; it cannot close a block in its parent. Dynare refuses: an empty loop body prints `syntax error, unexpected ENDFOR`, a trailing operator in `@#define f(x) = x+` prints `syntax error, unexpected EOL`, and an unparenthesized chain such as `1 in [1] in [true]` prints `syntax error, unexpected IN`. A blank line or comment counts as a loop body; an empty iteration array with a nonempty body is valid.

**Warrant**

The range selects the written directive or expression that owns the refusal. An empty loop body selects the closing keyword without indentation or a trailing comment. Syntax messages retain the pinned unexpected token; a redundant expected-token list can be omitted to keep the line short.

**Fix**

Close the macro block with the matching directive, add the intended loop body, complete the function expression before the end of the definition, or parenthesize each membership test.
