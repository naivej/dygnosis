### W208: Heterogeneity equation count does not match

The number of equations written in `model(heterogeneity=…)` does not equal the number of endogenous names written in `var(heterogeneity=…)` for that dimension. `#` locals and `[static]` rows are not counted. This is the same written-count check as **W013** for the aggregate model.

Dynare's own refusal counts again after it adds helper variables for leads and lags. That later count stays silent here. A file with one household variable and one equation that uses `c(+1)` does not warn, even if Dynare later inserts a helper.

**Fix**

Add or remove a household equation, or add or remove a `var(heterogeneity=…)` name, so the two written counts match.
