### E254: osr_params_bounds before osr_params

``osr_params_bounds`` appears and there is no earlier ``osr_params`` statement. Dynare refuses: `you must have an osr_params statement before the osr_params_bounds block.`

**Fix**

Put ``osr_params`` above ``osr_params_bounds``.

**Range warrant**

The range selects the owning `osr_params_bounds` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
