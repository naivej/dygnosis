### E301: planner_discount with a declared optimal_policy_discount_factor

``ramsey_model(planner_discount=…)`` is used while ``optimal_policy_discount_factor`` is already exists at the command, including a name generated by an earlier policy command. Dynare refuses: `ramsey_model: the 'planner_discount' option cannot be used when the 'optimal_policy_discount_factor' parameter is explicitly declared.`

**Fix**

Drop the ``planner_discount`` option. Set the discount parameter with a parameter assignment instead.
