### W120: Stochastic command with no stochastic exogenous variable

The file contains `stoch_simul` or `estimation`, but Dygnosis finds no written stochastic exogenous declaration. Names also declared with `varexo_det` are excluded from this check. This Warning does not establish whether the numerical procedure will succeed.

**Next step**

Review the intended command and shock setup. If the model needs stochastic shocks, declare them with `varexo` and use them in the model equations. An unused dummy shock can cause a separate Dynare refusal.
