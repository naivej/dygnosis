### E220: DSGE-VAR bayesian_irf shock count

``estimation`` estimates a DSGE-VAR and passes ``bayesian_irf``, but the number of shocks differs from the number of observed variables. Dynare refuses: `When estimating a DSGE-Var and the bayesian_irf option is passed to the estimation statement, the number of shocks must equal the number of observed variables.`

**Fix**

Adjust the ``varexo`` or ``varobs`` lists so the two counts are equal.
