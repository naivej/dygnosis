### E372: prior statement without the shape option

A dotted ``prior`` statement carries no ``shape``. Dynare refuses: `You must pass the shape option to the prior statement.` The sentence is the same for the plain, ``std(…)``, ``corr(…)`` and joint forms.

**Fix**

Pass ``shape=beta`` (or the distribution you intend).

**Range warrant**

The range selects the dotted statement's `prior` keyword, rather than the target name. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
