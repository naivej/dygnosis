### E090: Observed variable is not a declared endogenous variable

A name listed in ``varobs`` is not a declared endogenous variable. They refuse: `e is not endogenous.`

**Warrant**

The editor names the ``varobs`` role and, when the name is already declared as something else, says so; their string is only `N is not endogenous.`

**Fix**

Declare the variable in ``var``, or remove it from ``varobs`` if it was a typo or an exogenous/parameter name.
