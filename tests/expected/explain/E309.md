### E309: Deflator contains a non-stationary endogenous variable

The deflator expression of a ``var(deflator=…)`` statement uses a variable that is itself declared with a deflator. Dynare refuses: `The deflator contains a non-stationary endogenous variable. This is not allowed. Please use only stationary endogenous and/or {log_}trend_vars.`

**Fix**

Use a stationary variable or a trend variable as the deflator.
