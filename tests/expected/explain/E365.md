### E365: svar without the chain option

``svar`` was written without the ``chain`` option. Dynare refuses: `A 'chain' option must be passed to the 'svar' statement.`

**Fix**

Pass ``chain=N``; the number must name the matching ``markov_switching`` chain.

**Range warrant**

A missing required choice or chain selects the `svar` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
