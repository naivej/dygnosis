### E341: ms_estimation without no_create_init, datafile and initial_year

``ms_estimation`` was written without ``no_create_init`` and without one of ``datafile`` / ``initial_year``. Dynare refuses: `If you do not pass no_create_init to ms_estimation, you must pass the datafile and initial_year options.` One sentence covers every missing combination.

**Fix**

Add ``no_create_init``, or pass both ``datafile`` and ``initial_year``.

**Range warrant**

Missing command requirements select the `ms_estimation` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
