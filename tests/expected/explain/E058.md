### E058: Undeclared variable in a block that names symbols

A block or option names a symbol that is not declared at that point in the file. This includes `initval` / `endval`, shock and path stanza targets, `subsamples` heads and copy sources, scoped path references, `irf_shocks`, and the older name slots listed in the catalog. Dynare refuses with `Unknown symbol: undeclared_zzz` (some sites add a full stop and a `nostrict` hint). A bare undeclared name in a `shock_paths` value is a separate no-message Dynare crash and stays quiet.

**Warrant**

The editor names the undeclared entry and its block; Dynare's string is generic.

**Fix**

Declare the variable before its use, or correct the name.
