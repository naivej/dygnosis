### E319: Ramsey constraint is not an inequality

A ``ramsey_constraints`` entry is not an inequality. Dynare refuses: `Ramsey constraint has an incorrect form: This expression is not an inequality`.

**Warrant**

For an equality such as `y=0`, Dynare instead stops at the generic `unexpected EQUAL` syntax error. The editor keeps the existing non-inequality sentence to identify the constraint form that needs repair.

**Fix**

Write ``y > bound``, ``y < bound``, or ``lower < y < upper``.
