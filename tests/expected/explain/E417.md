### E417: endval change operation needs nondefault learning

An `endval` row uses `+=` or `*=` without `learnt_in>1` or a DATE. Dynare refuses: `endval: 'e += ...' line not allowed unless 'learnt_in' option with value >1 or date is passed` (or `*=` in place of `+=`).

**Fix**

Use `=`, or set the intended later `learnt_in`.
