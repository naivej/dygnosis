### E479: mcp tag in a heterogeneous model

A heterogeneous equation uses an ``[mcp=…]`` tag on a declared variable. Dynare refuses: `'mcp' tags are not allowed in heterogeneous model blocks`. An unknown left-hand side keeps the existing variable error, and ``mcp`` together with ``⟂`` keeps **E180**.

**Fix**

Write the condition with ``⟂`` or ``_|_``.
