### E439: Semi-structural command lacks a required option

A var_model, trend_component_model, var_expectation_model, or pac_model lacks one of its required options. Dynare refuses while parsing: `You must pass the 'OPTION' option to the 'COMMAND' statement.`

**Fix**

Add the required option to that command.

**Range warrant**

A missing required option selects the owning `var_model`, `trend_component_model`, `var_expectation_model`, or `pac_model` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
