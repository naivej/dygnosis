### E405: Shock path lag reaches before its period

An exogenous `shock_paths` value uses a variable reference that remains after simplification, and its lag reaches before the integer period. Dynare refuses: `shock_paths: a lag of 1 is not allowed at period 1`. A reference removed while Dynare simplifies the value does not cause this refusal; for example, `0*self.e(-1)` is quiet at period 1, while `self.e(-1)` reports E405.

**Fix**

Move the path to a later period or use a shorter lag.
