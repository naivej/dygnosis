### E188: Plain aggregate equation count mismatch

The number of written aggregate model equations does not match the number of endogenous variables. Dynare refuses: `There are 2 equations but 1 endogenous variables!` Dynare may change these counts when it rewrites a model. W013 provides guidance for other written-count mismatches.

**Warrant**

The transport already labels Errors, so the diagnostic omits Dynare's severity prefix.

**Fix**

Match model equations to distinct endogenous variables.

**Range warrant**

The range selects the first safely mapped aggregate `model` keyword in execution order. The count still combines aggregate blocks. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
