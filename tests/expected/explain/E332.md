### E332: homotopy_setup name is not a parameter or exogenous variable

A ``homotopy_setup`` row names a symbol that is neither a parameter, a ``varexo``, nor a ``varexo_det`` variable. Dynare refuses: `homotopy_val: y should be a parameter or exogenous variable`.

The name must have the required type when this row, head, or option is read. Earlier successful `change_type` statements count; later declarations or type changes do not. Repeated macro copies use their own parser context.

**Fix**

Use a parameter or an exogenous variable.
