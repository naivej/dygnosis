### E411: prev reference requires a later learning period

A `prev` reference appears in a default `shock_paths` block or `learnt_in=1`. Dynare refuses: `The syntax prev.u is not accepted in a 'shock_paths' block without the 'learnt_in' option or in a 'shock_paths(learnt_in=1)' block`.

**Fix**

Use a later integer or DATE `learnt_in`, or another supported reference.
