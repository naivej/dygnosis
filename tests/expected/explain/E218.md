### E218: initval/endval all_values_required is incomplete

``initval`` or ``endval`` was opened with ``all_values_required`` but some variables have no assignment. Dynare refuses: `You have not set the following endogenous variables in initval:`; `You have not set the following exogenous variables in initval:`; `You have not set the following endogenous variables in endval:`; `You have not set the following exogenous variables in endval:`.

**Fix**

Assign every endogenous and exogenous in that block, or drop ``all_values_required``.
