### W062: Circular @#include detected

Two or more files include each other in a loop. The message names the chain, for example `a.mod -> b.mod -> a.mod`.

**Common causes**

- A submodel was refactored and now includes its parent
- Two helper files cross-include each other for shared
  parameters or steady-state definitions
- A copy-paste mistake duplicated the include in the wrong
  direction

**Fix**

Break the cycle by removing one `@#include` along the chain. If both files genuinely need a shared block, extract that block into a third file and have both parents include it.
