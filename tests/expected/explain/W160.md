### W160: Named companion file was not found

A catalog option or quoted path names a companion file that this tool could not resolve next to the `.mod` or on the search paths. This is an extra Warning: they accept a missing named file at check. Missing convention files (`FILENAME_steadystate.m`, `FILENAME_prior_restrictions.m`, `run_FILENAME.m`) and a missing identifier helper are not this code.

**Fix**

Add the file next to this `.mod`, correct the path, or add its directory to the search paths.
