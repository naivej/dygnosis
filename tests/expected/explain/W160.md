### W160: Named companion file was not found

A named option or quoted path points at a companion file that was not found next to the `.mod` or on the search paths. Missing convention files (`FILENAME_steadystate.m`, `FILENAME_prior_restrictions.m`, `run_FILENAME.m`) and a missing identifier helper are not this warning.

**Fix**

Add the file next to this `.mod`, correct the path, or add its directory to the search paths.
