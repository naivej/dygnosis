### W012: Helper assignment without a declaration

A name is assigned without a declaration on a line before the first `model`, `initval`, `steady_state_model` or `shocks` block. If none of those blocks is present, the check considers all helper assignments. The name may be intended as a model parameter or only as a helper value.

**Next step**

If the name is a model parameter, declare it in `parameters`. If it is only a helper value, confirm that the assignment is intentional.
