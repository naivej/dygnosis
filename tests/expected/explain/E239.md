### E239: Undeclared name in a command symbol list

A trailing symbol list on ``stoch_simul``, ``estimation``, ``calib_smoother``, ``ramsey_policy``, ``discretionary_policy``, ``osr``, or the ``osr_params`` statement names a symbol that is not declared. Dynare refuses: `{cmd}: Variable {name} was not declared.`

**Fix**

Declare the symbol, or remove it from the list.
