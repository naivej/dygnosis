### E343: conditional_forecast_paths periods and values counts differ

A ``var`` row of ``conditional_forecast_paths`` lists a different number of ``periods`` and ``values`` entries. Dynare refuses: `shocks/conditional_forecast_paths: variable Pie: number of periods is different from number of shock values`. A range such as ``1:4`` counts as one entry.

**Fix**

Give one value per period entry.
