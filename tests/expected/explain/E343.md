### E343: Scheduled shock or conditional forecast counts differ

A deterministic `shocks`/`mshocks` row or `conditional_forecast_paths` row lists a different number of `periods` and values. Dynare refuses: `shocks/conditional_forecast_paths: variable Pie: number of periods is different from number of shock values`. A range such as `1:4` counts as one entry.

**Fix**

Give one value per period entry.
