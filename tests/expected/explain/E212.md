### E212: Estimated parameter used in a shock expression

Dynare refuses: `some estimated parameters (…) also appear in the expressions defining the variance/covariance matrix of shocks; this is not allowed.`

This check uses the final symbol type after successful `change_type` statements, rather than the list where the name was declared.

**Fix**

Use a calibrated parameter in the shocks block, or drop that name from ``estimated_params``.
