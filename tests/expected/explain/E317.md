### E317: Name is not endogenous, or is an exogenous deterministic

A name has the wrong declared role in a slot that requires an endogenous variable, or a `varexo_det` name is used where only plain exogenous variables are allowed. Dynare refuses `N is not endogenous.` or `N is an exogenous deterministic.` This includes controlled-path `exogenize`, scheduled shock/path rows, `self`/`prev`/`learnt_in` references, and the older prior, calibration, and moment slots.

**Fix**

Use `var` for an endogenous slot and `varexo` for a plain exogenous slot.
