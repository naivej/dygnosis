### E317: Name is not endogenous, or is an exogenous deterministic

A name that must be endogenous is not. Dynare refuses `N is not endogenous.`, and a ``varexo_det`` name on a ``std(…)`` / ``corr(…)`` prior head gets their other sentence, `N is an exogenous deterministic.` The surfaces are the ``optim_weights`` weights, a ``conditional_forecast_paths`` `var` row, and a prior head.

**Fix**

Name an endogenous variable.
