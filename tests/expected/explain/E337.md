### E337: Same endogenous variable excluded twice

One `model_remove` / `model_replace` statement or `include_eqs` / `exclude_eqs` selection removes two equations for the same endogenous variable.

**Warrant**

Dynare refuses: `Variable c was excluded twice via a model_remove or model_replace statement, or via the include_eqs or exclude_eqs option`. Dynare looks the printed name up at the loop index, so it can name a symbol that was not excluded at all; the editor names the variable that was excluded twice.

**Fix**

Remove just one of those equations, or correct their `endogenous` tags. See [Dynare's equation-selection rules](https://www.dynare.org/manual/running-dynare.html#exclude-eqs).
