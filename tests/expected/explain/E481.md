### E481: Incorrect steady_state_model target type

A ``steady_state_model`` output name has an incompatible type. Scalar and multiple-output assignments allow an ordinary endogenous, a parameter, or a temporary mod-file local. An unknown output name becomes a temporary after parsing the right-hand side. A function registered by that right-hand side is already known when its output names are checked. Dynare refuses: `e has incorrect type`.

This check uses the symbol type at that assignment, after the right-hand side and before the output is registered. A later ``change_type`` does not change that earlier decision. Heterogeneous variables and parameters are incompatible targets until a prior successful type change makes them ordinary.

**Warrant**

The message keeps Dynare's sentence. The editor range points at the incompatible written output name instead of the parser's range for the assignment.

**Fix**

Assign an ordinary endogenous, parameter, or temporary name. Use a different output name from the function being called.
