### E258: Several varobs statements

The file has more than one ``varobs`` statement. Dynare refuses: `varobs: you cannot have several 'varobs' statements in the same MOD file`.

**Fix**

Keep a single ``varobs`` statement.

**Range warrant**

The range selects the later `varobs` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
