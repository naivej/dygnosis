### E383: method_of_moments without a data file

A ``method_of_moments`` statement asks for ``GMM`` or ``SMM`` but names no ``datafile``. Both methods match moments against data, so the file is required. Dynare refuses: `The 'method_of_moments' statement requires a data file to be supplied via the 'datafile' option.`

``IRF_MATCHING`` does not need one. The file itself need not exist yet at this step; a named one that is missing is **W160**.

**Fix**

Add ``datafile='your_data.csv'``.
