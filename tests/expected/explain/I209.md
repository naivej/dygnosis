### I209: Declaration has no long_name

At least one `var`, `varexo`, `varexo_det`, or `parameters` name has no nonempty explicit `long_name`. This is a writing preference; it does not mean Dynare will refuse the model.

Each note counts eligible symbols from one written declaration statement. Each symbol is counted once in its scope and belongs to its first eligible declaration. Repeated macro executions of the same written statement contribute to one note per model file. Generated auxiliaries, model-local names, and other declaration kinds are not counted. Incomplete expansion withholds the note. The note points to the declaration statement.

Use **Add long names** to give each symbol counted by this note its own name. For example, the action adds `(long_name='y')` beside `y` in `var y;`. It changes only the symbols counted by this note, including symbols in an included file. Empty literal values are filled in place; existing nonempty values stay as written. TeX, partition options, comments, and other declaration options stay unchanged. If the include belongs to several model files, the action title identifies the selected model file. It shows how many rows were skipped when an edit is not safe. Repeated macro text is edited only when one literal value works for every affected copy; otherwise it stays as written. After an input changes, request the current action again.
