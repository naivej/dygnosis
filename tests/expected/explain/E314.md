### E314: filter_initial_state lag not used by the model

A ``filter_initial_state`` entry uses a lag that the model does not carry: the entry's ``lag`` stands for the model lag ``lag - 1``. Dynare refuses: `filter_initial_state: variable y does not appear in the model with the lag -3 (see the reference manual for the timing convention in 'filter_initial_state')`.

**Fix**

Match an entry's lag to the model: for ``y(-3)`` in the model, write ``y(-2)`` here.
