### E311: filter_initial_state name is not endogenous or exogenous

A ``filter_initial_state`` entry names a symbol that is neither endogenous nor exogenous (for example a parameter). Dynare refuses: `filter_initial_state: rho should be an endogenous or exogenous variable`.

The name must have the required type when this row, head, or option is read. Earlier successful `change_type` statements count; later declarations or type changes do not. Repeated macro copies use their own parser context.

**Fix**

List an endogenous or exogenous variable.
