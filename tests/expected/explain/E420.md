### E420: Shock path refers to itself at lag zero

A `shock_paths` value for `e` retains `self.e` without a lag or at lag zero. Dynare refuses: `in the definition of 'e' in a 'shock_paths' block, the use of 'self.e' without a lag is not allowed, since it is a circular reference`. The check uses references that remain after Dynare simplifies the value: `0*self.e` is quiet, while `self.e` reports E420. `self.u` at zero is allowed in a path for `e`.

**Fix**

Use a lagged `self.e` or another variable.
