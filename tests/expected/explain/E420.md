### E420: Shock path refers to itself at lag zero

A path for `e` uses `self.e` without a lag or at lag zero. Dynare refuses: `in the definition of 'e' in a 'shock_paths' block, the use of 'self.e' without a lag is not allowed, since it is a circular reference`. `self.u` at zero is allowed in a path for `e`.

**Fix**

Use a lagged `self.e` or another variable.
