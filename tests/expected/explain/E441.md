### E441: VAR expectation needs one expression source

var_expectation_model needs either variable or expression, and rejects both together. Dynare refuses while parsing with the corresponding `You must pass either` or `You can't pass both` sentence.

**Fix**

Keep exactly one of variable and expression.

**Range warrant**

When both `variable` and `expression` are absent, the range selects `var_expectation_model`. When both are present, it keeps the existing range. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
