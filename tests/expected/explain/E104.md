### E104: More than one planner_objective with Ramsey

With ``ramsey_model`` or ``ramsey_policy``, only one ``planner_objective`` statement is allowed. Dynare refuses: `there can only be one planner_objective statement`.

**Fix**

Keep a single ``planner_objective``.

**Range warrant**

The range selects the later `planner_objective` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
