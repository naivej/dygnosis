### E240: Wrong type in a command symbol list

A trailing symbol list names a declared symbol of the wrong type. Dynare refuses with one of four lists, each naming the types that command accepts: `{cmd}: Variable {name} is not one of {endogenous}`, `{endogenous, exogenous}` (``rplot``, ``dynasave``, ``dynatype``), `{endogenous, epilogue}` (``plot_shock_decomposition``), or `{parameter}` (``osr_params``, whose sentence prints `osr: `).

**Fix**

Use a symbol of the type the command accepts, or remove it from the list.
