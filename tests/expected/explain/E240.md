### E240: Wrong type in a command symbol list

A trailing symbol list names a declared symbol of the wrong type: those lists hold endogenous variables, and ``osr_params`` holds parameters. Dynare refuses: `{cmd}: Variable {name} is not one of {endogenous}` (``{parameter}`` for ``osr_params``).

**Fix**

Use a symbol of the type the command accepts, or remove it from the list.
