### W042: Endogenous variable missing from steady_state_model

The `steady_state_model` block does not assign a value for every endogenous variable. Dynare warns: `variable 'c' is not assigned a value`. Dynare will fall back to the `initval` value (or zero).

**Fix**

Add the missing assignments. For a numerical solve, use Dynare (for example `steady;` in MATLAB/Octave).
