### E416: Namespace reference in a controlled path

A controlled `shock_paths` stanza uses `self`, `prev`, `learnt_in`, or a database namespace in its value. Dynare refuses: `The syntax self.e is not accepted in an 'endogenize' stanza of a 'shock_paths' block`.

**Fix**

Use a plain expression or an allowed `initval`/`init` reference.
