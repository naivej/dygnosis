### E425: Learnt-in shock paths need expectation-errors commands

A nondefault `shock_paths(learnt_in=…)` block needs both expectation-errors setup and solver, without regular perfect-foresight setup or solver. Dynare refuses: `the 'shock_paths(learnt_in=…)' block can only be used in conjunction with the 'perfect_foresight_with_expectation_errors_setup' and 'perfect_foresight_with_expectation_errors_solver' commands.`

**Fix**

Use the expectation-errors setup and solver, or a default shock-path block.
