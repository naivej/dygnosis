### E275: Namespace-qualified symbol

An expression uses a bare namespace-qualified value such as `pkg.foo` where that variable form is not allowed. Dynare refuses: `Namespace-qualified symbol {ns}.{name} not allowed in this context`. A qualified function call such as `pkg.foo(1)` is a different form and is allowed in a steady-state RHS.

**Fix**

Use a declared value without a namespace prefix, or supply the intended function arguments.
