### E331: init2shocks second name is not exogenous

The second name of an ``init2shocks`` pair is not a ``varexo`` variable; ``varexo_det`` does not count here. Dynare refuses: `init2shocks: rho should be an exogenous variable`.

The name must have the required type when this row, head, or option is read. Earlier successful `change_type` statements count; later declarations or type changes do not. Repeated macro copies use their own parser context.

**Fix**

Put a ``varexo`` variable second.
