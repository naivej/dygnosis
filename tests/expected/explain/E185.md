### E185: Invalid or reused OccBin constraint name

A ``bind`` / ``relax`` tag piece or an ``occbin_constraints`` name is not a letter-or-underscore identifier, or ``occbin_NAME_bind`` is already declared as a variable. Dynare refuses: `The string '{}' is not a valid Occbin constraint name (contains unauthorized characters)` and `The name '{}' is already used. Please use another name for Occbin constraint '{}'`.

**Fix**

Use letters, digits, and underscores, and pick a name that does not collide with ``occbin_NAME_bind``.
