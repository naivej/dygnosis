### E312: filter_initial_state exogenous variable without a lag

A ``filter_initial_state`` entry gives an exogenous variable the lag 0. Dynare refuses: `filter_initial_state: exogenous variable e must be provided with a lag`.

The name must have the required type when this row, head, or option is read. Earlier successful `change_type` statements count; later declarations or type changes do not. Repeated macro copies use their own parser context.

**Fix**

Give the exogenous variable a negative lag.
