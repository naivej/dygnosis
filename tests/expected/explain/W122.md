### W122: Deep parameter assigned a non-finite value

A parameter that is used in the model equations is assigned a non-finite value (``NaN`` or ``Inf``) while a run command (``steady``, ``stoch_simul``, ``perfect_foresight_*``, ``estimation``, ...) is present. Dynare's deep-parameter calibration check rejects ``NaN`` / ``Inf`` parameters.

**Fix**

Assign a finite numeric value before the run command.
