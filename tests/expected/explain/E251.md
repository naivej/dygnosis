### E251: Exogenous variable in planner_objective

``planner_objective`` uses an exogenous or undeclared name. Dynare refuses: `You cannot include exogenous variables (or variables of undeclared type) in the planner objective. Please define an auxiliary endogenous variable like eps_aux=epsilon and use it instead of the varexo.`

**Fix**

Replace the exogenous name with an auxiliary endogenous variable.
