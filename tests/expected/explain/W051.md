### W051: Exogenous variable set in initval

A variable declared with `varexo` is assigned in `initval`. This can be intentional in a perfect foresight model: a following `steady` command computes the steady state conditional on the exogenous values in `initval`. In a stochastic model, exogenous innovations use zero as their initial value.

**Next step**

Check whether the assignment matches the intended simulation. This Warning does not compute a steady state.
