### E431: Subsample target has an invalid final symbol type

A `subsamples` declaration or copy has a target whose final type is neither parameter, plain exogenous, nor endogenous. Dynare accepts through its JSON checks but refuses when writing MATLAB files: `subsamples: invalid symbol type for d`. The first target name determines the type, including after `change_type` or `var_remove`.

**Fix**

Use a parameter, `varexo`, or `var` target, or change the target's final type.
