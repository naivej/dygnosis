### E391: matched_irfs periods and weights counts differ

In one ``matched_irfs`` row the ``weights`` list holds more than one element and does not match the number of periods. Dynare refuses: `matched_irfs: the 'periods' and 'weights' keywords are not followed by the same number of elements`. A single weight is accepted and copied across the periods.

**Fix**

Give one weight per period, or a single weight for the whole row.
