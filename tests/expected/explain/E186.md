### E186: Unused written endogenous variable

The endogenous variable is not used in the written model equations. Dynare refuses: `Error: x not used in the model block`. Dygnosis cannot detect every case that becomes unused after Dynare rewrites the model.

**Warrant**

The transport already labels Errors, so the diagnostic omits Dynare's severity prefix.

**Fix**

Use x in a model equation or remove its declaration.
