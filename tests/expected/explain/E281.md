### E281: Mod-file local used inside model

A name first used without a declaration in an expression outside ``model`` is used in a model expression. This includes external-function arguments, planner objectives, constraints, growth factors and deflators. The role is the one known when this use was parsed. Dynare refuses: `Variable {name} not allowed inside model declaration. Its scope is only outside model.`

**Fix**

Declare the name as ``var``, ``varexo``, or ``parameters`` if it belongs in the model.
