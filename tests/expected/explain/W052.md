### W052: Endogenous variable missing from initval

The `initval` block omits one or more endogenous variables. Dynare assumes zero for variables omitted from `initval`; the block can supply solver guesses and, in a perfect foresight model, initial or terminal conditions.

**Next step**

Check the omitted names and provide values where needed for your model. Dygnosis does not test convergence or compute a solution.

**Range warrant**

The range selects the owning `initval` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
