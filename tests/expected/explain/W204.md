### W204: Unknown symbol in a load_params_and_steady_state file

The data file of ``load_params_and_steady_state`` holds a name that is not declared at that point in the ``.mod``. Dynare accepts and warns: `Unknown symbol zzz in w204_params.txt`.

**Fix**

Remove the entry from the data file, or declare the symbol above the ``load_params_and_steady_state`` statement.
