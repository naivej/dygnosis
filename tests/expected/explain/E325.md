### E325: external_function bare second derivative without a bare first

A bare ``second_deriv_provided`` asks the top-level function for the second derivative while the first derivative comes from somewhere else. Dynare refuses: `If the second derivative is provided in the top-level function, the first derivative must also be provided in that function.`

**Fix**

Add a bare ``first_deriv_provided``, or name the second-derivative function.
