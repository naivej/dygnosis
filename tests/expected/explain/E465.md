### E465: Heterogeneous shock variance on the wrong type

A ``shocks(heterogeneity=…)`` block sets a variance on a name that is not a heterogeneous exogenous variable. Dynare refuses: `shocks: setting a variance on 'y' is not allowed, because it is not a heterogeneous exogenous variable`.

**Fix**

Set the variance on a ``varexo(heterogeneity=…)`` name.
