### W060: Requested IRF has no written stochastic shock size

A `stoch_simul` command explicitly requests IRFs with `irf>0` or `irf_shocks`, but no variance or standard error is written for a requested `varexo` shock. A bare `stoch_simul`, a `varexo` declaration alone, and an explicit zero variance do not trigger this Warning. This is an editor Warning; Dynare does not report it before MATLAB.

**Fix**

If the IRF request is intended, specify a variance or standard error for the shock in a `shocks` block, or provide its shock size through the intended alternative source.
