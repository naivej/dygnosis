### E020: Undeclared identifier in model block

An identifier appears in the `model` block but is not declared as a `var`, `varexo`, or `parameters` symbol or defined as a model-local variable. Dynare refuses: `Unknown symbol: alpph`.

**Warrant**

The editor sentence names the undeclared identifier in the equation and may include a Did-you-mean suggestion; Dynare's string is the generic `Unknown symbol`.

**Fix**

- Add the identifier to the appropriate declaration block
- Correct a typo (a close-match suggestion may appear)
- For a model-local variable, define it before use inside the model block, for example `# helper = alpha + beta;`
