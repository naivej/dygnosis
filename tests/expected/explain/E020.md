### E020: Undeclared identifier in model block

An identifier appears in the `model` block but is not declared as a `var`, `varexo`, or `parameters` symbol. They refuse: `Unknown symbol: alpph`.

**Warrant**

The editor sentence names the undeclared identifier in the equation and may include a Did-you-mean suggestion; their string is the generic `Unknown symbol`.

**Fix**

- Add the identifier to the appropriate declaration block
- Correct a typo (a close-match suggestion may appear)
- If the symbol is a local helper, define it in the parameter   section before use
