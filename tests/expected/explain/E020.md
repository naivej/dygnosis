### E020: Undeclared identifier in model block

An identifier appears in the `model` block but is not declared as a `var`, `varexo`, or `parameters` symbol. The diagnostic names the exact identifier and the equation it appears in.

**Fix**

- Add the identifier to the appropriate declaration block
- Correct a typo (the LSP suggests close matches when available)
- If the symbol is a local helper, define it in the parameter   section before use
