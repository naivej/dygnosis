### E182: Forbidden expression in occbin_constraints

An ``occbin_constraints`` expression uses a lead/lag, a model-local, an exogenous variable, ``EXPECTATION``, ``var_expectation``, ``pac_expectation``, ``pac_target_nonstationary``, or ``SUM()``. Dynare refuses, for example: `Leads and lags on variables are forbidden in 'occbin_constraints'. Note that you can achieve the same effect by introducing an auxiliary variable in the model.`; `Model local variable z cannot be used in 'occbin_constraints'.`; `Exogenous variable e cannot be used in 'occbin_constraints'.`; `The 'expectation' operator is forbidden in 'occbin_constraints'.`; `The SUM() operator is forbidden in occbin_constraints block`. ``STEADY_STATE`` itself is allowed.

**Fix**

Use contemporaneous endogenous variables (and parameters). Introduce an auxiliary variable for leads, lags, or exogenous terms.
