### I208: Counted equation has no name tag

At least one surviving counted model equation has no nonempty `name` tag. This is a writing preference; it does not mean Dynare will refuse the model.

Each note counts unnamed equations from one written `model` block, or surviving replacement rows from one `model_replace` block. `#` locals, static-only rows, and removed equations are not counted. Repeated macro executions of the same written block contribute to one note per model file. Incomplete expansion withholds the note. The note points to the block that owns the equations.

Use **Add equation tags** to add names such as `eq1` and `eq2` to the unnamed equations counted by this note, including equations in an included file. It chooses the lowest unused positive `eqN`. Names do not change when equations move. Empty literal `name` values are filled in place; existing names and other tags stay as written. If the include belongs to several model files, the action title identifies the selected model file. It also shows how many rows were skipped when an edit is not safe. Repeated macro text is edited only when one literal name works for every affected copy; otherwise it stays as written. After an input changes, request the current action again.
