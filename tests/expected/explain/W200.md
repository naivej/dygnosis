### W200: Nonsmooth operator in a stochastic context

Dynare warns: `you are using a function (max, min, abs, sign) or an operator (<, >, <=, >=, ==, !=) which is unsuitable for a stochastic context; see the reference manual, section about "Expressions", for more details.`

**Fix**

Rewrite without those operators, or drop the stochastic command if the file is meant to be perfect foresight.
