### E025: Invalid model-local (`#`) variable

A model-local variable defined with `#` reuses a name with another symbol type, or uses an undeclared name before its first definition. Dynare refuses: `… has wrong type or was already used on the right-hand side. You cannot use it on the left-hand side of a pound ('#') expression`.

An earlier `model_local_variable name;` declaration permits a forward use. It does not supply an expression in another model scope. A model scope is the aggregate model, or the heterogeneous model for one dimension; several blocks can use that scope.

**Fix**

- Rename the helper if its name has another symbol type
- Move the `#` definition above an undeclared first use, or declare the local before that use

**Range warrant**

For an undeclared forward use, the editor points at the first read that prevents the later definition. A wrong-type or undeclared self-use points at the definition target.
