### E025: Model-local variable shadows a declared symbol

A model-local variable defined with `#` uses the same name as a declared `var`, `varexo`, or `parameters` symbol. That hides the declared steady-state value inside the model block and can make solver diagnostics misleading.

**Fix**

- Rename the model-local helper, for example `#y_local = ...`
- Or remove the declaration if the name was intended to be only   a model-local helper
