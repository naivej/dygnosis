### E219: dsge_prior_weight declared with dsge_var

``estimation`` passes the ``dsge_var`` option while ``dsge_prior_weight`` is already declared as a model variable or parameter. Dynare refuses: `dsge_prior_weight should not be declared as a model variable / parameter when the dsge_var option is passed to the estimation statement.`

**Fix**

Remove the ``dsge_prior_weight`` declaration; the ``dsge_var`` option declares it implicitly.
