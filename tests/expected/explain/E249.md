### E249: Skewness on a non-exogenous name

``estimated_params`` lists ``skew`` on a name that is not exogenous. Dynare refuses: `in `estimated_params' block, skewness can only be specified for exogenous variables, not for '{name}'.`

This check uses the final symbol type after successful `change_type` statements, rather than the list where the name was declared.

**Fix**

Use ``skew`` only on a ``varexo`` name.
