### E093: estimated_params references an undeclared symbol

An ``estimated_params`` entry names a symbol that is not declared with the expected role: a plain entry must name a parameter, an ``stderr`` entry must name a shock or observed variable, and a ``corr`` entry must name two declared shocks or variables. They refuse: `Unknown symbol: not_a_param`.

**Warrant**

The editor names the ``estimated_params`` role (parameter, stderr, or corr); their string is the generic `Unknown symbol`.

**Fix**

Declare the symbol, or correct the name / entry type.
