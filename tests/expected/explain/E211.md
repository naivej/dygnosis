### E211: Nonsmooth operator on an exogenous in a linear non-PF model

Dynare refuses: `you have declared your model 'linear' but you are using a function (max, min, abs, sign) or an operator (<, >, <=, >=, ==, !=) on an exogenous variable in a non-perfect-foresight context.`

**Fix**

Drop ``linear``, add a perfect-foresight solver, or rewrite without that operator on exogenous variables.
