### E259: Several varexobs statements

The file has more than one ``varexobs`` statement. Dynare refuses: `varexobs: you cannot have several 'varexobs' statements in the same MOD file`.

**Fix**

Keep a single ``varexobs`` statement.

**Range warrant**

The range selects the later `varexobs` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
