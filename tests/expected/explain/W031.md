### W031: Symbol declared twice with the same type

The same identifier is declared more than once with the same type: in `var`, `varexo`, `varexo_det`, or `parameters`, as the same trend form twice, twice in the `epilogue` block, or as a function name repeated on `external_function` statements (`name=`, `first_deriv_provided`, `second_deriv_provided`). Dynare accepts and warns `Symbol y declared twice.`

**Fix**

Remove the redundant declaration.
