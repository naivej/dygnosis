### E170: Multiple occbin_constraints blocks

The file has more than one ``occbin_constraints`` block. Dynare refuses: `Multiple 'occbin_constraints' blocks are not allowed`.

**Fix**

Keep a single ``occbin_constraints`` block.

**Range warrant**

The range selects the later `occbin_constraints` keyword. The keyword excludes options, body, and `end`. If its written file or token cannot be verified, the previous mapped range remains.
