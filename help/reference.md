# Reference

This reference lists Dygnosis commands, diagnostic explanations, recognized
Dynare command options and MCP tools from the installed Help edition.
**Explain a check** can show an explanation from the selected engine; its
version is shown with the result.

Configuration controls are in **Dygnosis: Open Settings** and linked from each
[workflow topic](get-started.md). [Keyboard Shortcuts](action:shortcuts) contains
the command bindings.
